# Release boundary

The local app, provider setup, real specialist dispatcher, controlled teaching visuals, consent-based storage, companion observations, rule adapter, launchers and source packaging are implemented. Real account access and a live acceptance session remain external requirements.

Optional future work: a larger educator-reviewed catalogue; facilitator-verified custom names; verified isolated-phoneme recordings; a validated acoustic assessor; speech barge-in; multiple authenticated users; and native hosted Pipelex execution. None of those external services is silently required by the default Dust/Gradium app.
