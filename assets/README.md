# Teaching material

`phonetics.json` contains the controlled starter catalogue: 17 names/words and 11 written patterns. It includes ordinary French pronunciation references, explicit syllable boundaries, silent-letter notes, short contextual models and optional meaning emoji. It is authored teaching material, not a learner record.

The app renders spelling as escaped local SVG images in a clear large font. Syllables appear as separate tiles with dashes; whole words follow in one tile. Emoji are reused instantly and are withheld until a companion confirms the active word attempt. No generated image service is needed.

Extend the catalogue by checking the actual pronunciation, segmentation, silent letters, patterns, transfer examples and model text. Review names with their owner. Keep spelling exact, do not put IPA in spoken text, and run the offline catalogue checks after changes. A literacy professional should review new linguistic content, and actual TTS should be auditioned.
